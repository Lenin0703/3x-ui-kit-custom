# План выпуска и эксплуатации

## Проверки перед объединением в main

- Unit-тесты Python и `bash -n` на Ubuntu 24.04.
- Верификация хешей зафиксированных источников с GitHub.
- Тест на пустой VM: установка, проверка `x-ui`, `kit`, `kit-sub`.
- Тест отказа на VM с установленной панелью: снимок всех файлов до/после.
- Тест тайм-аута и блокировки GitHub Releases; перенос официального архива локально.
- Проверка REALITY, XHTTP, Hysteria2, Shadowsocks и остальных протоколов,
  а также подписки в Prizrak-box на Windows и Android.
- Восстановление VM из снапшота после каждого сценария.

## Запланировано для второго этапа

- Консистентный снимок SQLite через `sqlite3.backup`, включая WAL.
- Архив сертификатов, настроек nginx, systemd, секретов с правами `0600`.
- Проверки целостности копии до любой операции обновления.
- Dry-run плана изменения и предупреждения о несовместимости.
- Автоматический откат с проверкой API, служб и доступности подключений.

## Границы первого этапа

Первый этап безопасно **отказывает** при обнаружении существующей установки.
Переустановка на живом сервере, даже если первый запуск оборвался, пока запрещена.
Это лучше, чем удаление файлов в автоматическом восстановлении, до появления
транзакционного бэкапа и тестов на изменение данных.
