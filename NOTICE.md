# Авторство и лицензии

Исходный проект: [3X-UI KIT](https://github.com/itsnotkubrick/3X-UI_KIT), автор **itsnotkubrick**, лицензия MIT.
3X-UI KIT Custom — независимый набор проверок, патчей и безопасного запуска,
неофициальный по отношению к авторам оригинального проекта.

Код оригинального KIT загружается из его фиксированного тега `v1.2.1`,
сверяется по Git Blob SHA-1 и остаётся под оригинальной лицензией MIT,
включая первоначальное авторство. Изменения Custom распространяются по MIT.

**Важные сторонние компоненты:** панель [3X-UI](https://github.com/MHSanaei/3x-ui)
имеет лицензию GPL-3.0, Xray-core — MPL-2.0, а acme.sh — GPL-3.0.
Этот репозиторий не переобозначает их лицензии как MIT и не включает в себя
их исходники. Устанавливаемые компоненты могут подчиняться собственным лицензиям.

Список остальных зависимостей и уведомления об авторских правах:
